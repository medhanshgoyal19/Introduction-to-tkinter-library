# Introduction to Tkinter Library

A simple beginner-friendly **Python GUI project** created using **Tkinter**.

## 📖 About

This project demonstrates the basic concepts of creating a **Graphical User Interface (GUI)** in Python using the built-in **Tkinter** library.

The application creates a **500 × 500** window with a **blue background** and includes a **label, red button, and text entry box**.

## ✨ Features

- 🖥️ **500 × 500 GUI window**
- 🔵 **Blue background**
- 🏷️ **Text label**
- 🔴 **Greet! button**
- ⌨️ **Text input field**
- 📍 **Widget positioning using `place()`**
- 🔄 **Tkinter event loop using `mainloop()`**

## 🛠️ Technologies Used

- **Python 3**
- **Tkinter**

## 📚 Concepts Covered

This project demonstrates the use of:

- `tk.Tk()` — creating the **main window**
- `title()` — setting the **window title**
- `geometry()` — setting the **window size**
- `config()` — configuring **window properties**
- `Label()` — displaying **text**
- `Button()` — creating a **button**
- `Entry()` — accepting **user input**
- `place()` — **positioning widgets**
- `mainloop()` — running the **GUI event loop**

## ⚠️ Current Status

The **Greet!** button is currently a **visual button** and does not perform an action yet.

The project can be extended by connecting the button to a **function** and using the text entered in the **input box**.
